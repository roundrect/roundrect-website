Swurl

A link router for macOS. Swurl becomes your default browser, and every link you click in another app — Mail, Slack, a terminal — opens in the browser and profile your rules choose. When no rule decides, a wheel of your browsers appears at the pointer.

Status: not yet released. There is no download and no install command yet. Release news will be posted on the blog, which has an Atom feed.

What it is

  • Swurl.app is a menu bar app that receives the links you click and shows the wheel.
  • swurl is a command line tool that routes links the same way, and explains why.

Your rules live in one YAML file. They are tried in order, and the first one that matches decides where the link opens.

What it does

  • Opens the right profile. Chrome, Edge, Brave and other Chromium browsers open straight into the profile a rule names, whether the browser is running or not. Any other browser or app opens as it is.
  • Rules on more than the address. Match on the host, the path, the whole URL, the app the link came from, the keys you are holding and the apps that are running.
  • The wheel. Links no rule decides open a wheel at the pointer, with each profile’s picture and its browser’s badge. Point at one, or press ⌘1–⌘9. Hold ⌥ when you click a link to get the wheel whatever the rules say.
  • Never loses a link. A broken config, a browser that is not installed or a profile that no longer exists brings up the wheel instead of guessing.
  • Explains itself. swurl route <url> --explain shows which rule would match and why, without opening anything.
  • Works as $BROWSER. Tools that open a browser from the terminal go through your rules too. With one rule per CLAUDE_CONFIG_DIR, each Claude Code account’s login opens in its own Chrome profile.

The file

Targets name a browser and, optionally, a profile. Rules say when to use which. Anything else goes to default, which is the wheel unless you name a target.

Profiles are named by their folder (Default, Profile 1), because display names can repeat and change. swurl browsers --yaml prints a ready-to-paste target for every profile on your Mac, and swurl validate reports every problem at once, with line numbers and a suggested fix.

The command line

CommandWhat it does
swurl initCreate a commented starter config
swurl validateCheck the config, and its browsers and profiles against this Mac
swurl browsers [--yaml]Installed browsers and their profiles; --yaml prints ready-to-paste targets
swurl route <url> [--explain]Which rule decides, and why; nothing is opened
swurl open <url> [--dry-run]Route and open a link; --dry-run shows what would launch
swurl default [set|restore]Show the default browser, make Swurl the default, or put the previous one back

route can simulate any context (the sending app, held keys, running apps, environment) so you can test a rule before you rely on it. Most commands take --json.

Becoming the default browser

Swurl only becomes your default browser when you ask it to, from its menu or with swurl default set, and macOS asks you to confirm. It records the previous default first, so Restore (or swurl default restore) puts it back.

Permissions

To show your profiles’ names and pictures, Swurl reads each browser’s list of profiles. macOS treats that as data from other apps and does not ask for it, so you turn it on yourself: Swurl’s settings open System Settings › Privacy & Security › Files & Folders › Swurl, where there is one switch per browser. Swurl notices the change by itself.

Links still open without it; the wheel just can’t show those profiles. Swurl only reads browsers’ files and never changes them. It is not sandboxed, because it has to launch other browsers with a profile.

Privacy

  • Swurl makes no network connections of its own and has no analytics.
  • It keeps a log of its decisions on your Mac, in ~/Library/Logs/Swurl/, with query strings removed from every link.

Known limits

  • Sign-in windows that apps open themselves, such as Mail’s Add Account, go to Safari rather than through Swurl.
  • Links you click inside a browser or a Chrome web app stay there. Routing those will need a browser extension.

Requirements

  • macOS 15 (Sequoia) or later.

Status

Swurl has not been released. When it is, this page will say where to download it and the blog will carry the news. Follow the Atom feed to hear about it.
